## 🎯 About

A dynamic news portal that fetches and displays real-time news articles using the GNews API. The application provides users with up-to-date news from various sources, categories, and topics with a clean and intuitive interface.

### ✨ Key Highlights

- 📡 **Real-time News** - Live news updates via GNews API
- 🔍 **Search Functionality** - Find news by keywords
- 📱 **Responsive Design** - Works on all devices
- ⚡ **Fast & Dynamic** - JavaScript-powered content loading

## 📡 API Integration

This project uses the **GNews API** to fetch news articles. 

### Setting Up API Key

1. Get a free API key from [GNews.io](https://gnews.io/)
2. Add your API key to `script.js`:
   ```javascript
   const API_KEY = 'your_api_key_here';
   ```

### API Features Used

- Search news by keyword
- Filter by category
- Fetch top headlines
- Get article metadata (title, description, image, source)

## 🏁 Getting Started

### Prerequisites

- Modern web browser
- GNews API key (free tier available)
- Internet connection for API calls

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/mzain2004/Dynamic-News-Portal.git
   ```

2. **Navigate to directory**
   ```bash
   cd Dynamic-News-Portal
   ```

3. **Add API Key**
   - Open `script.js`
   - Replace `YOUR_API_KEY` with your GNews API key

4. **Open in browser**
   ```bash
   # Open index.html in your browser
   # Or use a local server
   python -m http.server 8000
   ```
